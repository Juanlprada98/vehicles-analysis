# Vehicle Data Dashboard

Esta aplicación web fue creada con Streamlit como parte de un proyecto educativo.
Permite visualizar datos del archivo vehicles_us.csv mediante:

- Un histograma interactivo del odómetro.
- Un gráfico de dispersión entre precio y odómetro.

Los gráficos son generados con Plotly Express y la app se ejecuta en Render.
